    Models

    What each preset runs and what the pickers offer. Nothing changes until you save.

    Presets

    Each preset sends two to six model families as reviewers and has one Consensus engine. Daily and Open Models take Free models only.

    Models in the pickers

    Row order is picker order. Free default is preselected for Free accounts, Pro only locks a model for everyone else, Consensus offers it as engine. A model in use is still referenced by a preset, Watch or judge.

    Advanced

    Rarely needed. Watches, Topics, the API and Compare runs use these.

    Consensus engines

    The Consensus picker in this order; the first one is preselected. Aliases such as Gemini-Pro follow the provider's current model.

    Judges

    They find the differences, mark claims and run Resolve. Standard engines use the Standard judge, Pro engines the Pro judge at reduced effort.

    Who judges which engine

    Auto takes the first family with a key in priority order, OpenAI first. A manual pick goes first and falls back to Auto.

    Chat memory

    Condenses older turns from the third turn on. The family follows the turn's engine; pick a cheap model in each. Without it a plain summary is used.

    Watch models

    One answer model per family and a Consensus engine for each profile, at least two families. Plus deliberately uses the same model profile as Free. Actually runs names what the next run uses and why a family drops out.

    Reasoning effort

    Savings asks verified models for low effort (Mistral: none) and leaves fixed settings alone. It lowers effort, not the price per token.
